# programming-words.txt — vocabulary that belongs to this profession, not to English.
#
# Curated here, MIT like the rest of the repository, and kept apart from english-words.txt.gz on
# purpose: that list is imported public-domain English and must stay auditable as such, while every
# line below is a decision someone made and a reviewer can question.
#
# Rules for adding a line:
#   - it must be a word a programmer writes in code and a dictionary will never carry
#     (`stdin`, `argparse`, `rglob`), not an English word the dictionary already has;
#   - it must be ASCII, lowercase, one per line, at least 4 characters — shorter segments never
#     reach this check (MIN_SEGMENT);
#   - it must NOT be a Portuguese word. This file is not a back door for the locale rule: adding
#     `pedido` here would silence the very defect the check exists to find.
#
# Seeded on 2026-08-26 from the segments this repository's own code produced that the English list
# did not know — measured, not imagined.
