## Why

`skills/documentation/references/check-doc-structure.py` served as the audit in
`solvelab/ferdinand#583` (PR #584, merged at `eea8b20`). The guard ferdinand wrote right after it,
`test/unit/docs-structure.test.ts`, found defects the checker had let through. Reproduced on
2026-09-24 against this repository at `1abce62`, each case below returns `findings: 0` while
`--selftest` still reports `7/7 injected defects detected`:

1. **R1 is blind to a document with no `##`.** `check_index` returns early when there is no level-two
   heading, so a 350-line catalog made only of `###` owes nothing (ferdinand `docs/SIGNALS.md`).
2. **R2 splits a cell on an escaped pipe.** `tables()` splits on every `|`, so a cell that writes
   `\|` as text is measured as two short halves (ferdinand `docs/DEPLOYMENT.md:112`, 141 characters).
3. **R1 counts a link from anywhere as the index.** `linked` collects every `](#…)` in the document,
   so a section cited in the body counts as indexed while missing from the index. The rule text
   says "the index links every `##`"; the check measured something weaker.

And the detector's `--selftest` is not in CI. `skills-authoring` already requires a mechanically
checkable rule to be enforced by a script whose self-test runs in CI; this detector ships the
self-test and nothing runs it. If one of its rules stopped firing, nothing would fail.

## What Changes

- **Modified** `skills/documentation/references/check-doc-structure.py`:
  - R1 falls back to `###` when a document has no `##`.
  - R1 counts only the links inside the index block, from the index heading to the next heading.
  - R2 treats `\|` as cell text.
  - `--selftest` gains one injected defect per blind spot, and the clean document stays silent.
- **Modified** `skills/documentation/references/information-architecture.md`: R1 states the `###`
  fallback and that only the index block counts. R2 states that an escaped pipe is cell text.
- **Modified** `skills/documentation/SKILL.md`: `metadata.version` bump.
- **Modified** `.github/workflows/ci.yml`: a step runs `check-doc-structure.py --selftest`.
- **Modified** `openspec/specs/skills-authoring`: a detector a skill ships under `references/` is
  gated like the catalog's own validators, and a field defect it missed becomes an injected case.

## Capabilities

### Modified Capabilities

- `skills-authoring`: *Authoring rules are machine-enforced* covers detectors a skill ships under
  `references/`. Their self-test runs in CI, and a defect found in the field that the detector missed
  is added to the self-test as an injected case before the fix lands.

## Impact

- `skills/documentation/`: one script, one reference, a version bump. No skill is added, renamed or
  removed, so catalog composition and `npx skills add --list` are unchanged.
- Wrapper trees regenerated by `generate.sh`: `plugins/docs/` and `cursor/` carry the body.
- `.github/workflows/ci.yml`: one new step.
- Consumer repositories: a document that passed before can now fail R1 or R2. Measured against
  `solvelab/ferdinand@eea8b20` with the #583 exclusions before the change is closed.
