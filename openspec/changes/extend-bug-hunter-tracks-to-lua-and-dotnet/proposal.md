# Change: Close the generation and scoring layers on the Lua and .NET tracks

## Why

The change archived as `2026-09-07-update-bug-hunter-generation-and-scoring` published a rule in
`openspec/specs/skills-catalog/spec.md`: the adversarial rite separates enumerating, generating and
scoring, and each conditional technique carries the condition under which it pays. It then delivered
the commands for exactly one of the three stack tracks. `skills-authoring` is explicit about what
that leaves behind:

> A skill that prescribes a **step** SHALL also give the command that performs it whenever a
> plausible wrong command exists, and SHALL name the wrong one. A step stated without a method is
> executed by whatever command looks obvious, which is how a wrong one becomes the de facto
> instruction.

Someone working in FiveM/Lua or on a .NET plugin now reads in the stack-agnostic SKILL.md that the
hunt can be generated and scored, and finds nothing about how in the track that is supposed to serve
them. The omission was honest — nothing was measured for those ecosystems at the time — but silence
is not the same as an answer.

## What Changes

- `references/track-fivem-lua.md` gains a section that reports what the ecosystem actually offers,
  probed rather than recalled, and what follows for the rite when the answer is "nothing".
- `references/track-dotnet-plugin.md` gains the same, and says where the scoring question is already
  answered for the failure class that track exists for.
- `bug-hunter` → 2.6.0, and the `Not version-bound` block records the probe.

Neither track receives a prescribed command this change could not run. Where the ecosystem has no
tool, the probe that establishes the absence is what gets written down, so the next reader does not
repeat the search.

### Modified Capabilities

- `skills-catalog`: MODIFIED *The adversarial rite separates enumerating, generating and scoring* —

  absence and what the rite does instead, rather than leaving the layer unmentioned there.

- `skills/bug-hunter/references/track-fivem-lua.md`, `track-dotnet-plugin.md`, and the version block
  of `skills/bug-hunter/SKILL.md`.
- Generated trees regenerated by `./generate.sh`.
- No catalog composition change and no trigger change; the eighteen skills that defer to
  `bug-hunter` are unaffected.
