## Why

The `documentation` skill governs whether a claim in a document is **verifiable**. It says nothing
about whether the document is **navigable**, and a reader cannot verify a fact they cannot find.

Measured on `solvelab/ferdinand@66346d4`, a repository documented under this skill: a 1006-line
`README.md` with no table of contents; a reference table whose largest cell is 205 characters, with
15 cells over 120; 101 environment variables with zero anchors, so none can be linked from an issue
or reached through the GitHub Outline; and a 127-line `## O modo sem cluster` section carrying eight
`###` children that belong to other sections.

The skill's own closing rule is *ship the checker*. It never says what to check about organization,
so nothing was checked, and none of those four defects can be reproved by any gate today.

## What Changes

- **New** `skills/documentation/references/information-architecture.md`: seven organization rules,
  each with its published source, an example of the defect and an example of the correct form.
- **New** `skills/documentation/references/check-doc-structure.py`: the detector for the rules whose
  measured false-positive rate justifies one, following the `code-locale` precedent of a skill
  shipping its own checker under `references/`.
- **Modified** `skills/documentation/SKILL.md`: points at the new reference, carries the rules that
  hold without exception, and bumps `metadata.version`.
- **Modified** `openspec/specs/skills-authoring`: a rule the catalog publishes as review-only must
  record the measurement that made it review-only, not only the label.

Rules whose detector proves unreliable ship **without** a validator, with the measurement written
beside them. This change does not promise seven validators.

## Capabilities

### Modified Capabilities

- `skills-authoring`: a doctrine rule published as review-only carries the measurement — findings,
  hand-confirmed defects, false positives, and the sample they were measured on — instead of the
  bare label the current wording accepts.

## Impact

- `skills/documentation/` — one new reference, one new script, an edited `SKILL.md` and a version bump.
- Wrapper trees regenerated by `generate.sh`: `claude/`, `codex/`, `copilot/` carry pointers;
  `cursor/` and `plugins/` carry the body.
- No consumer repository is edited by this change. `solvelab/ferdinand#441` and
  `solvelab/ferdinand#442` apply the rules there and are blocked on this one.
- No change to catalog composition: no skill added, renamed or removed, so `npx skills add --list`
  returns the same set at the same count.
