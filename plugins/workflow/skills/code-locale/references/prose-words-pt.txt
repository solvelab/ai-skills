# prose-words-pt.txt — Portuguese function words, the evidence check-prose-locale.py counts.
#
# One word per line, lowercase, accents kept as typed (`só` is not `so`, `não` is not `nao`).
# Every entry must be a word that is Portuguese and NOT English: the detector asserts, at load and
# in --selftest, that this file and prose-words-en.txt share no word. Words both languages carry
# (`a`, `as`, `no`, `do`, `me`, `sem`, `via`, `um`, `em`, `para`, `era`, `ver`, `num`, `ali`,
# `nova`, `anterior`, `for`, `logo`, `ate`, `ha`, `alias`) are deliberately absent — a shared word is evidence for
# neither side. How the list was built and pruned: prose-words.SOURCE.md.
