# Herring gull (*Larus argentatus*)

regimes: `articulated-body` (wing) + a steered trajectory
view: **pure profile.** Drawing mirrored wings — the view from below — on a profile body puts two
viewpoints in one animal. That defect took three failed fixes before it was named.

| fact | value | source |
|---|---|---|
| proportions | expressed in units of body length L | *L. argentatus* references |
| wing | two-bone: arm (humerus+forearm) then hand; the hand carries the primaries | avian anatomy |
| downstroke vs upstroke | asymmetric — the downstroke is the power stroke; the upstroke folds the hand to cut drag | flight mechanics |
| joint at the wrist | the parent shape must extend PAST the pivot, or the joint opens a gap when it bends. Overlap and coverts were both tried first and both failed | measured in this repo |
